================================================================================
                    SmirnovTorrent - Инструкция по использованию
================================================================================

Добро пожаловать в SmirnovTorrent - лёгкий и современный BitTorrent клиент!

================================================================================
                           БЫСТРЫЙ СТАРТ
================================================================================

🚀 САМЫЙ ПРОСТОЙ СПОСОБ (Windows):
   Просто дважды кликните по файлу start.bat - веб-интерфейс откроется 
   автоматически в вашем браузере!

📋 ИЗ КОМАНДНОЙ СТРОКИ:
   smirnovtorrent.exe webui
   (запускает веб-интерфейс на порту 8080)

================================================================================
                           ОСНОВНЫЕ ФУНКЦИИ
================================================================================

1. ДОБАВЛЕНИЕ ТОРРЕНТА:
   - Нажмите кнопку "Обзор" (📁)
   - Выберите .torrent файл на компьютере
   - Нажмите "Добавить"
   - Загрузка начнётся автоматически

2. УПРАВЛЕНИЕ ЗАГРУЗКОЙ:
   - "Пауза" - приостановить загрузку
   - "Возобновить" - продолжить загрузку
   - "Открыть папку" - показать файлы (доступно после завершения)
   - "Удалить" - удалить торрент

3. СТАТИСТИКА:
   - Загрузка - текущая скорость скачивания
   - Отдача - текущая скорость раздачи
   - Пиры - количество подключённых пиров
   - Торренты - активные загрузки

================================================================================
                           КОМАНДНАЯ СТРОКА
================================================================================

Полный список команд:

smirnovtorrent.exe help
   Показать справку по всем командам

smirnovtorrent.exe download <файл.torrent>
   Скачать торрент файл

smirnovtorrent.exe download <файл.torrent> -o <папка>
   Скачать в указанную папку

smirnovtorrent.exe download <файл.torrent> -download-limit 1048576
   Ограничить скорость загрузки (байт/сек)

smirnovtorrent.exe download <файл.torrent> -upload-limit 524288
   Ограничить скорость отдачи (байт/сек)

smirnovtorrent.exe webui
   Запустить веб-интерфейс (порт 8080)

smirnovtorrent.exe webui 9000
   Запустить веб-интерфейс на порту 9000

smirnovtorrent.exe info <файл.torrent>
   Показать информацию о торренте

smirnovtorrent.exe version
   Показать версию программы

================================================================================
                           НАСТРОЙКИ
================================================================================

Файл конфигурации: smirnovtorrent.json

Пример настроек:
{
  "WebUIPort": 8080,           // Порт веб-интерфейса
  "DownloadRateLimit": 0,      // Лимит загрузки (0 = без ограничений)
  "UploadRateLimit": 0,        // Лимит отдачи (0 = без ограничений)
  "EnableDHT": true,           // Включить DHT сеть
  "EnablePEX": true,           // Включить обмен пирами
  "EnableEncryption": true,    // Включить шифрование
  "DefaultDownloadDir": "C:\\Downloads"  // Папка по умолчанию
}
