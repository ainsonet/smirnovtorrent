# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.14.x  | :white_check_mark: |
| 0.13.x  | :white_check_mark: |
| < 0.13  | :x:                |

## Reporting a Vulnerability

We take security seriously. If you discover a security vulnerability, please report it via GitHub's private vulnerability reporting feature.

## Security Features

### Implemented

- ✅ **MSE Encryption** (BEP 47) - Protects against ISP throttling
- ✅ **Info Hash Verification** - Ensures data integrity
- ✅ **Peer ID Validation** - Prevents spoofing
- ✅ **Rate Limiting** - Prevents abuse

## Security Best Practices

1. **Keep Updated**: Use the latest version
2. **Use Encryption**: Enable MSE encryption
3. **Firewall**: Configure properly
4. **Trusted Sources**: Download torrents from reputable sources
