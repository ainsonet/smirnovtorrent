Быстрый старт

🖥️ Командная строка

# Загрузить торрент файл
smirnovtorrent download example.torrent

# Загрузка с опциями
smirnovtorrent download file.torrent -o ~/Downloads

# Запустить веб-интерфейс
smirnovtorrent webui

# Показать информацию о торренте
smirnovtorrent info example.torrent

🌐 Веб-интерфейс

  1. Запустите start.bat
  2. Откройте http://localhost:8080 в браузере
  3. Нажмите "Browse" для выбора .torrent файла
  4. Нажмите "Add Torrent" для начала загрузки
  5. Мониторьте прогресс в реальном времени
