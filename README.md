# Веб-сайт SmirnovTorrent

Официальный веб-сайт SmirnovTorrent - Лёгкий BitTorrent клиент.

## Файлы

- `index.html` - Главная страница
- `styles.css` - Стили с тёмной темой
- `script.js` - Интерактивные функции
- `logo2.png` - Логотип проекта

## Настройка

### Цвета

Измените CSS-переменные в `styles.css`:

```css
:root {
  --primary: #0ea5e9;        /* Голубой */
  --success: #10b981;        /* Зелёный */
  --bg-primary: #0f172a;     /* Тёмно-синий */
  /* ... другие переменные */
}
```

### Контент

Измените `index.html`, чтобы изменить:
- Текст в герое
- Список функций
- Ссылки для скачивания
- Шаги документации

## Технологии

- **HTML5** - Семантическая разметка
- **CSS3** - Современное стилизование с CSS Grid и Flexbox
- **Vanilla JavaScript** - Без фреймворков
- **Тёмная тема** - Тёмный UI по умолчанию с акцентными цветами

## Поддержка браузеров

- Chrome/Edge (рекомендуется)
- Firefox
- Safari
- Opera
